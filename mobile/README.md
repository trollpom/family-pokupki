# Android и iOS

Это стартовая конфигурация Capacitor 8, а не опубликованные сборки. Пакеты мобильного проекта ещё не устанавливались; Android Studio, Xcode и реальные устройства в этой среде недоступны. Вместо готового клиентского пакета в www лежит явный экран состояния разработки.

Следующие работы: выделить клиент из серверного Vinext-приложения, подключить защищённый API и проверенный нативный сценарий входа, добавить обработку камеры/штрихкодов, нативное «Поделиться», локальный кэш и очередь синхронизации. Затем заменить содержимое www, выполнить установку зависимостей и cap add/sync, подписать и протестировать сборки.

Не задавать server.url как производственное решение: загрузка удалённого сайта предназначена для разработки и сама по себе не заменяет мобильную реализацию.

Идентификатор app.sobrano.personal временный. Перед выпуском согласовать постоянные идентификаторы и аккаунты магазинов с владельцем.

Документация: https://capacitorjs.com/docs/getting-started ; https://capacitorjs.com/docs/getting-started/environment-setup ; https://capacitorjs.com/docs/config .
