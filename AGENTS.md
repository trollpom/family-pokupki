# Разработка «Собрано»

## Источник проекта

- Основной репозиторий: `https://github.com/trollpom/family-pokupki.git`, основная ветка `main`.
- Все последующие изменения выполняйте в checkout этого репозитория и сохраняйте коммитами в GitHub. Перед работой сверяйтесь с актуальным состоянием удалённой ветки и локальными изменениями пользователя.
- Действующее приложение: `https://pokupki-family.awake-chub-6299.chatgpt.site`. Публикация Sites выполняется отдельно после проверок. GitHub является источником разработки; внутренний репозиторий Sites используется только для синхронизации подготовленного к публикации состояния.
- Сохраняйте существующий `project_id` из `.openai/hosting.json` и доступ только владельцу. Не создавайте дубликат Site. Следуйте доступному навыку Sites при публикации.

## Проверки

- Node >=22.13, pnpm версии из `packageManager`. Установка: `npm run install:ci`.
- Проверка типов: `node node_modules/typescript/bin/tsc --noEmit`.
- При правках логики запускайте соответствующие `tests/*-checks.mjs` и `tests/checks.mjs`; при изменении сборки или интерфейса выполняйте `npm run build`.
- Не меняйте уже применённые SQL-миграции: добавляйте новые в `drizzle/` с согласованной схемой.
- Для Netlify используйте `npm run build:netlify`, затем `tests/netlify-checks.mjs` и `tests/netlify-http-checks.mjs`. Правки режима Netlify сохраняйте в GitHub; не публикуйте их на Sites, если пользователь просит только Netlify. Инструкция: `docs/netlify.md`.
- Прямые импорты `cloudflare:workers` заменяются только Next.js webpack-сборкой на `lib/netlify/runtime-env.ts`. Не подключайте Netlify SQLite/Blobs к Vite Worker-сборке.

## Данные и текущее состояние

- Не коммитьте API-ключи, токены, cookie, `.env*`, `.dev.vars*`, базы, пользовательские выгрузки, `node_modules`, артефакты сборки и `.tsbuildinfo`. Реальные данные хранятся в D1.
- `AI_SECRET_ENCRYPTION_KEY` рабочего приложения нельзя менять без миграции зашифрованных ключей.
- Основной город: Нижний Новгород. Сети: Пятёрочка, Магнит, SPAR, Перекрёсток, Чижик, Лента, Ашан, Смарт. Статусы фактически доступных подключений описаны в README; не считайте блокированные источники подключёнными.
- Меню принято по умолчанию. Повторная замена блюда с ИИ меняет всю партию; ошибка сохраняет прежний рецепт.
- Проверяйте город, дату, условия акции, упаковку, вес и покрытие корзины. Не подменяйте неизвестные цены нулём или демонстрационными данными.
- Пользователь запросил электронные каталоги сайтов; не добавляйте PDF или OCR для цен.
