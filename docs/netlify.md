# Размещение «Собрано» на Netlify

В репозитории теперь два режима сборки. `npm run build` собирает Vinext/Cloudflare для Sites. `npm run build:netlify` собирает настоящий Next.js в `.next`; штатный адаптер Netlify упаковывает страницы и API в Functions. Настройки находятся в `netlify.toml` и имеют приоритет над автоматически предложенной сборкой.

## Первый деплой

1. Подключите `trollpom/family-pokupki`, ветку `main`. Base directory оставьте пустой, build command — `npm run build:netlify`, publish directory — `.next`. Node.js — 22.
2. В **Project configuration → Environment variables** добавьте секреты с областью **Functions** (или All scopes), доступные в Production. Не сохраняйте их в коде:

| Переменная | Значение |
| --- | --- |
| `APP_PASSWORD` | Личный пароль длиной от 16 символов. |
| `APP_SESSION_SECRET` | Отдельная случайная строка длиной от 32 символов. |
| `AI_SECRET_ENCRYPTION_KEY` | Base64 от 32 случайных байт для шифрования ключа DeepSeek. |

Для генерации случайной строки и ключа можно по отдельности выполнить локально: `node -e "console.log(require('node:crypto').randomBytes(32).toString('base64'))"`. Сохраните значения у себя. Смена пароля или секрета сессии сбрасывает вход. Ключ шифрования не меняйте после сохранения ключа DeepSeek без миграции данных.

3. Повторите деплой через **Deploys → Trigger deploy → Clear cache and deploy site** (в некоторых версиях интерфейса — Retry without cache).
4. Откройте адрес Netlify, войдите по паролю. Заполните параметры семьи и введите ключ DeepSeek внутри приложения. Без настройки пароля сайт показывает экран настройки; личные API закрыты.

Не отключайте `@netlify/plugin-nextjs` через `NETLIFY_NEXT_PLUGIN_SKIP`; не указывайте `dist` или `out` как папку Netlify. Если вручную добавляли старую версию плагина, удалите её из настроек Plugins и позвольте Netlify использовать текущий автоматический адаптер. Не добавляйте перенаправление `/* /index.html 200`: оно перекрывает серверные маршруты.

## Данные и ограничения режима

На Netlify используется встроенный **Netlify Blobs**, site-wide store `sobrano-database`. Не требуется отдельный аккаунт Cloudflare или сторонняя база. SQLite-снимок с неизменяемыми SQL-миграциями читается с strong consistency. Каждая SQL-операция и batch записываются с проверкой ETag; конфликт повторяет только SQL, а ошибка batch не сохраняет частичную запись. Списки, меню и зашифрованные ключи переживают перезапуск Functions и новые деплои. `/tmp` используется только на время обработки запроса и не является постоянной базой. Этот адаптер рассчитан на личное использование с небольшой базой; для массового коммерческого сервиса потребуется отдельное SQL-хранилище.

**Рабочая база Sites автоматически не переносится на Netlify.** Это отдельная установка с новым личным профилем. Прежнее приложение и его данные остаются в Sites. Не переносите рабочие токены, cookie или ключ шифрования через GitHub.

Вход ChatGPT доступен только на Sites. В режиме Netlify используется подписанная серверная cookie `HttpOnly; Secure; SameSite=Strict`; переданные посетителем заголовки `oai-authenticated-*` игнорируются. В этой личной версии один аккаунт владельца; отдельные аккаунты участников групп потребуют дополнительной реализации.

Сборщики магазинов работают через те же API и правила сопоставления. Фоновое расписание Sites не переносится в Netlify: пока обновление запускается в открытом приложении. Плановое обновление в закрытом приложении требует отдельного расписания Netlify. Лимиты времени Functions могут ограничивать длинное обновление и ИИ; незавершённая выгрузка Смарт сохраняет прогресс. Доступность сайтов магазинов в среде Netlify проверяется после первого запуска и не гарантируется локальной сборкой.

## Проверки

- `npm run build:netlify` — сборка Next.js для автоматического адаптера Netlify.
- `node tests/netlify-checks.mjs` — миграции, сохранение между запусками, атомарность batch, конкуренция, сессии и доступ к обновлению цен.
- `node tests/netlify-http-checks.mjs` — проверка собранного Next.js через HTTP и реального SDK Blobs с локальным сервером протокола. Не обращается к рабочей базе или аккаунту Netlify.
- Прежние `tests/*-checks.mjs` и `npm run build` — регрессии основного приложения и сборки Sites.

Документация: [Next.js на Netlify](https://docs.netlify.com/build/frameworks/framework-setup-guides/nextjs/overview/), [Netlify Blobs](https://docs.netlify.com/build/data-and-storage/netlify-blobs/).
